# Core Stock Pool (产业链全景映射版)

Use this fixed pool as a starting map for A-share leader tracking. This pool is structured by **Upstream (Materials/Equipment) -> Midstream (Manufacturing/Components) -> Downstream (Terminals/Applications)**. 
When analyzing news, you MUST perform cross-stream checks (e.g., if Midstream drops, check Upstream materials; if Downstream applications boom, check Midstream components).
