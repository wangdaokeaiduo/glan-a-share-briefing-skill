# 市场正在挖掘的方向 — 板块纵深映射知识库

## 使用说明

当格兰扫描到当天涨幅靠前的板块时，**必须加载本文件**，沿着下方映射树做纵深扩散，判断资金正在往哪些更细分的上游/极深上游延伸，并在报告中输出「🔍 市场正在挖掘的方向」模块。

**核心原则**：市场的挖掘逻辑永远是 **成品厂先涨 → 材料/部件商补涨 → 设备/工艺商跟涨**。格兰要做的是比市场快半步，在成品厂涨的第一天就预判材料端的机会。

## 挖掘深度评级标准

格兰对每个细分方向的"挖掘深度"必须做出分层评级：

| 评级 | 含义 | 判断标准 | 操作含义 |
| --- | --- | --- | --- |
| 🔴 **概念期** | 市场刚开始联想，纯题材驱动 | 无订单、无收入、只有概念新闻或研报提及 | 高风险博弈，快进快出，不可重仓 |
| 🟡 **订单期** | 有客户验证/小批量订单，但未形成规模收入 | 有客户送样/认证新闻、有小批量出货但收入占比<10% | 中等风险，可观察介入，需持续跟踪订单进展 |
| 🟢 **业绩期** | 订单已转化为规模收入，业绩可见 | 收入占比>15%、有批量供货合同、季报/半年报可验证 | 可以作为中线配置方向 |

## 常见挖掘路径模板

### 游资挖法（自上而下、快速扩散）
1. 板块龙头涨停 → 当天下午或次日，资金开始找"同板块低位股"
2. 成品厂涨完 → 次日资金转向上游材料（树脂、铜箔、电子布）
3. 材料涨完 → 资金再转向设备商或化学品（PCB化学品、曝光设备）
4. **特征**：速度快（通常2-3天完成一轮扩散）、持续性差、回调猛烈

### 机构挖法（自下而上、逻辑驱动）
1. 从下游需求爆发（如AI服务器出货量翻倍）出发
2. 逆推供应链瓶颈环节（如高速CCL供不应求 → 树脂/电子布产能紧张）
3. 找到"量价齐升"的极深上游材料商
4. **特征**：速度慢（可持续数周至数月）、有业绩兑现支撑、回调后可加仓
